Tennis Match Simulation

A Python project exploring tennis match-winning probabilities through randomized simulation.

Overview

This project simulates tennis matches and estimates the probability of Player A winning under different scoring configurations.

Features

* Simulates points, games, sets, and matches.
* Estimates match-winning probabilities through repeated simulations.
* Compares outcomes under different scoring configurations.
* Visualizes results using Matplotlib.

Technologies

* Python
* Random simulation
* Matplotlib

How to Run

Install Matplotlib:

pip install matplotlib

Run the program:

python tennis.py
